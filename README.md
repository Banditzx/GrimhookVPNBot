Профессиональное решение для автоматизации продаж и управления VPN-доступом. Интегрируется с панелью **3x-ui** (протокол VLESS Reality).

## ✨ Основные функции
* **Автоматизация:** Выдача настраиваемого тестового периода новым пользователям.
* **Подключение:** Генерация VLESS-ключей напрямую из бота через API 3x-ui.
* **Оплата и продление:** бот принимает оплату через Telegram Stars и автоматически продлевает подписку пользователя.
* **Коды активации:** одноразовые ключи на 1–12 месяцев для отдельной продажи и активации в профиле бота.
* **Помощь:** Интерактивные инструкции по настройке для Android, iOS, Windows и macOS.
* **Админ-панель:** Веб-интерфейс на Streamlit для управления пользователями, редактирования кода и просмотра логов.

## 🛠 Установка и запуск (Docker)
# Предварительные требования
Python 3.10+

Панель управления 3X-UI

Создан inbound с параметром "Безопасность Reality"

Telegram бот (созданный через @BotFather)

## 1. Клонируйте репозиторий:
```bash
git clone https://github.com/Banditzx/GrimhookVPNBot.git
cd GrimhookVPNBot
```

## 2. Запустите проект:
```bash
docker-compose up -d
```

В Docker/Portainer база SQLite хранится в volume `grimhook_vpn_data` по пути `/app/data/users.db`. Не удаляйте этот volume при обновлении контейнера, иначе потеряются пользователи, подписки, платежи, коды активации и сообщения.

Для обновления Git Stack используйте **Pull and redeploy** в существующем Stack. Имя контейнера назначается Compose автоматически, а имя volume остается `grimhook_vpn_data`. Если переносите установку из отдельного контейнера или другого Stack, сначала проверьте, что старая база хранится в этом volume и он подключен к `/app/data`, затем остановите старый экземпляр перед запуском нового. Это освобождает порт `8501` и исключает одновременный запуск двух ботов с одним токеном. Если база находится в другом volume или внутри старого контейнера, сначала перенесите ее; volume с данными удалять не нужно.

### Коды активации

В веб-админке откройте **Коды активации**, выберите срок от 1 до 12 месяцев и количество от 1 до 100. Скачайте созданную партию в CSV для дальнейшей продажи. Полные ключи доступны только после генерации в текущей сессии; база хранит хеши и окончания ключей.

Пользователь нажимает **Активировать код** в меню или статусе профиля и отправляет ключ. Один месяц равен 30 дням. Действующая подписка продлевается от своей даты окончания, истекшая или новая — от момента активации. Каждый ключ используется один раз. Неиспользованные ключи можно отозвать в админке; история содержит Telegram ID активировавшего пользователя и выданный срок.

Если VPN-профиль уже есть, бот обновляет его срок в 3X-UI. Если профиля нет, пользователь получает его кнопкой **Подключиться**. При недоступности 3X-UI срок сохраняется в базе, а существующая фоновая синхронизация повторяет обновление. Повторно вводить использованный ключ не нужно. Таблица кодов создается автоматически при запуске обновленного бота или веб-панели.

Проверка кодов и страницы админки после установки зависимостей: `python -m unittest discover -s tests -v`. Тесты используют временные базы; запросы к Telegram и 3X-UI заменены тестовыми ответами.

## 3. Доступ к админ-панели: http://IP_ВАШЕГО_СЕРВЕРА:8501

### Первый вход

При первом запуске автоматически создается учетная запись администратора по умолчанию:

| Поле | Значение |
| --- | --- |
| Логин | `admin` |
| Пароль | `admin` |

Логин и хеш пароля хранятся в той же SQLite-базе и Docker volume, что и данные бота. Пароль можно изменить в разделе **Профиль**. Повторные запуски не сбрасывают измененный пароль.

Сессии входа хранятся в базе и действуют 7 дней. Выход завершает текущую сессию, смена пароля завершает остальные сессии. Переменная `ADMIN_PANEL_PASSWORD` больше не используется, ее можно убрать из Portainer Stack.

# ⚙️ Ручная установка

## 1. Создайте окружение и установите зависимости:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```


## 2. Настройте конфигурацию

Создайте файл `src/.env` на основе `src/.env.example` и заполните параметры:

```env
BOT_TOKEN=telegram_bot_token_from_botfather
ADMINS=123456789
TRIAL_DAYS=1

PRICE_1_DAY_RUB=25
PRICE_7_DAYS_RUB=125
PRICE_1_MONTH_RUB=350
PRICE_2_MONTHS_RUB=700
PRICE_3_MONTHS_RUB=1050

DISCOUNT_1_DAY_PERCENT=0
DISCOUNT_7_DAYS_PERCENT=0
DISCOUNT_1_MONTH_PERCENT=0
DISCOUNT_2_MONTHS_PERCENT=0
DISCOUNT_3_MONTHS_PERCENT=0

STAR_RUB_RATE=1.66
STAR_PRICE_MARKUP_PERCENT=10

XUI_API_URL=https://your-panel-domain:2053
XUI_HOST=your-vpn-host
XUI_BASE_PATH=/your-panel-secret-path
XUI_SERVER_NAME=Grimhook VPN
XUI_SUBSCRIPTION_BASE_URL=https://your-panel-domain:2096/sub
XUI_TOKEN=your_3x_ui_api_token
INBOUND_IDS=1
```

Основные параметры:

* `BOT_TOKEN` — токен Telegram-бота от `@BotFather`.
* `ADMINS` — Telegram ID администраторов через запятую.
* `TRIAL_DAYS` — длительность бесплатного тестового периода в днях.
* `PRICE_*_RUB` — цены тарифов в рублях.
* `DISCOUNT_*_PERCENT` — скидки на тарифы в процентах.
* `STAR_RUB_RATE` — ручной курс рубля к Telegram Stars.
* `STAR_PRICE_MARKUP_PERCENT` — наценка к цене в Stars.
* `XUI_API_URL`, `XUI_BASE_PATH`, `XUI_HOST`, `XUI_TOKEN` — параметры доступа к панели 3x-ui.
* `XUI_SUBSCRIPTION_BASE_URL` — публичный адрес сервера подписок без клиентского Sub ID, например `https://your-domain.com:2096/sub`. Укажите его и в переменных Portainer Stack. Бот добавляет актуальный `subId` конкретного клиента из API 3X-UI и показывает ссылку подписки вместо прямой VLESS/Trojan-ссылки. Если переменная пустая, остаются прямые ссылки.
* `INBOUND_IDS` — ID inbound через запятую: `2` для одного или `2,3,6` для нескольких. По умолчанию `1`; пустое значение недопустимо. Бот создает одного клиента на всех перечисленных inbound с общим Sub ID и сроком. Все они должны существовать и быть включены. Первая запись используется как основное подключение при выдаче прямой ссылки; для нескольких протоколов настройте `XUI_SUBSCRIPTION_BASE_URL` и используйте общую подписку. Передайте `INBOUND_IDS` также в переменные Portainer Stack.
* `XUI_MANAGED_CLIENT_PREFIX` — префикс клиентов 3x-ui, которыми разрешено управлять боту. По умолчанию `user_`; ручные профили без этого префикса бот не удаляет, не продлевает и не обновляет.

Пользователь оплачивает тариф Telegram Stars. После успешной оплаты бот сохраняет платеж, продлевает подписку в базе и синхронизирует срок действия VPN-профиля в 3x-ui.

Ссылку подписки можно открыть в браузере или добавить в VPN-приложение как подписку. Она содержит подключения, связанные с Sub ID этого клиента в 3X-UI, а не все профили с тем же Telegram ID. Для существующих профилей бот получает актуальный Sub ID при следующем нажатии «Подключиться». При пересоздании удаленного профиля Sub ID меняется; пользователь должен импортировать новую ссылку.

Если настроено несколько inbound, при следующем подключении существующему клиенту добавляются недостающие привязки. Профиль и Sub ID сохраняются, ранее добавленные вручную привязки не удаляются. При повторном нажатии уже выполненные привязки не добавляются заново. Продление и удаление выполняются для единого клиента через API 3X-UI и распространяются на его подключения. Бот управляет только клиентами с настроенным префиксом.

## 3. Запустите веб-панель:
```bash
streamlit run admin_panel.py
```
После запуска перейдите по адресу, который выдаст терминал (обычно порт 8501). Для авторизации используйте учетную запись из раздела [Первый вход](#первый-вход), затем нажмите кнопку «Запустить бота».

## 4. В веб-панели нажмите "Запустить бота".
